################
Instalación y Configuración
################

En esta sección se revisará el procedimiento para poder llevar a cabo el proceso de instalación del software de Limelight y configurar la cámara de manera exitosa.

Para descargar el software, en este link se encuentran las herramientas oficiales:

`Página oficial de descargas de Limelight <https://docs.limelightvision.io/docs/resources/downloads>`_


Acceso a la interfaz web
######################
Como primer paso, se debe instalar el Limelight Hardware Manager, el cuál es utilizado para:

- Detectar la Limelight conectada por USB
- Instalar o reinstalar el sistema (imaging)
- Actualizar firmware
- Diagnosticar problemas de conexión

Una vez que el software está instalado, es necesario establecer la comunicación con la Limelight.
La conexión puede realizarse mediante **Ethernet** o a través de la **red del robot**. Es importante que la computadora esté conectada a la misma red que el dispositivo.
